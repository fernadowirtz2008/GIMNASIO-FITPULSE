# Fitness DAW

Página web de un gimnasio creada como proyecto educativo.

## Tecnologías utilizadas

- HTML5: estructura de la página.
- CSS3: diseño y presentación.
- JavaScript: interacción con el formulario.
- Git: control de versiones.
- GitHub Pages: publicación en Internet.

## Estructura del proyecto

- `index.html`: página principal.
- `css/estilos.css`: estilos visuales.
- `js/app.js`: comportamiento interactivo.
- `.gitignore`: archivos excluidos del control de versiones.

## Ejecución local

Abre `index.html` en un navegador web.

## Publicación

Sube el proyecto a un repositorio de GitHub y activa GitHub Pages desde
**Settings → Pages**, seleccionando la rama `main` y la carpeta `/(root)`.

Nota: el formulario es una demostración local; no envía correos ni guarda datos.
